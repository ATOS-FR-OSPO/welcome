# Welcome

## Description

Ecran d'animation Oldschool pour montrer les possibilités d'utilisés ISPO et OSPO.

Inspiration des effets de démoscènes des années 80/90 et +

Ce projet est maintenu dans le cadre d'une démarche ISPO / OSPO afin de favoriser la réutilisation, la collaboration, la gouvernance open source et la contribution structurée.


### 1.2 Objectif de l'application

L'objectif est de montré uen base d'utilisation ISPO et OSPO


### 1.3 Identité visuelle

Charte graphique alignée avec **atos.net** :

| Élément | Valeur |
|---|---|
| Couleur primaire | `#0073E6` (bleu Atos) |
| Couleur secondaire | `#00005c` (bleu marine foncé) |
| Couleur accent | `#e3632b` (orange) |
| Texte principal | `#2b2b2b` |
| Gris clair (fond) | `#f2f2f2` |
| Gris bordures | `#cecece` |
| Police principale | `Raleway` (Google Fonts) |
| Police fallback | Verdana, Arial, Helvetica, sans-serif |


## Contexte 

Ce projet est juste un projet de test de faisabilité

## Fonctionnalités

L'animation montre plusieurs effets imbriqués

- Effet de sharder
- ScrollText
- Animation du logo
- Déformation du texte **welcome** en points

## deployer

Le déploiement vers OSPO s'effectue à partir du menu ISPO 

> Settings > Repository > Mirroring repositories
